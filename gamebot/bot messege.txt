【寶石座標函式】

使用者：在 gamebot/blitzbot.ipynb 新增 code cell。basex 和 basey 是左上角寶石中心點的位置，畫面有 8x8 顆寶石，間距為 gap。寫一個函式，接受 row（r）和 column（c），回傳該寶石的位置。

助理：新增 gem_position(r, c)，以 basex + c * gap 和 basey + r * gap 計算螢幕座標；r、c 從 0 開始。

【寶石顏色函式】

使用者：在 gamebot/blitzbot.ipynb 新增 code cell，完成 get_gem_color。函式接受 r、c 和畫面截圖 im，使用 pyautogui 取得該位置寶石的顏色並回傳。

助理：新增 get_gem_color(r, c, im)，使用 gem_position(r, c) 取得位置，再透過 im.getpixel((x, y)) 回傳截圖中的顏色。

【向左移動判斷】

使用者：在 gamebot/blitzbot.ipynb 新增 code cell，完成 can_move_left。函式接受 r、c 和 im，判斷寶石能否往左移動；可以則回傳 True，否則回傳 False。im 是能讀取寶石中心顏色的螢幕截圖。（此請求曾重複提出。）

助理：新增 can_move_left(r, c, im)，模擬與左側寶石交換，並檢查交換位置是否形成至少三顆同色的橫向或縱向連線；棋盤邊界會回傳 False。r、c 從 0 開始。

【其他方向移動判斷】

使用者：依照 can_move_left 的規格，完成 can_move_right、can_move_up 和 can_move_down。（此請求曾重複提出。）

助理：新增 can_move_right、can_move_up 和 can_move_down，並共用方向判斷函式，模擬與相鄰寶石交換及檢查三連線。

【限時自動移動】

使用者：在 gamebot/blitzbot.ipynb 新增 code cell：先存下目前時間並截圖，進入迴圈，對畫面中的每顆寶石判斷 can_move_left、can_move_right、can_move_up、can_move_down；若有可行方向，就將寶石 (r, c) 移往該方向並重新截圖。超過一分鐘就跳出迴圈。（此請求曾重複提出。）

助理：新增限時執行的自動操作 cell，掃描 8x8 棋盤，找到可行移動時拖曳寶石、等待畫面更新並重新截圖；沒有移動時重新截圖並稍作等待，直到時間超過一分鐘。
